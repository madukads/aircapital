# Urban Capital — Calculadora PWA

App mobile instalável via navegador (PWA).

---

## Como publicar na Vercel (grátis, 5 minutos)

1. Acesse https://vercel.com e crie uma conta gratuita
2. Clique em "Add New Project" → "Deploy from folder"
3. Arraste a pasta `urban-capital-pwa` para o upload
4. Clique em Deploy — em 30 segundos você terá um link público

---

## Como instalar no celular (Android)

1. Abra o link do app no Chrome
2. Toque no ícone de menu (⋮) no canto superior direito
3. Toque em "Adicionar à tela inicial"
4. Pronto — aparece como um app normal!

## Como instalar no celular (iPhone)

1. Abra o link no Safari
2. Toque no botão de compartilhar (□↑)
3. Role até "Adicionar à Tela de Início"
4. Toque em "Adicionar"

---

## Arquivos do projeto

```
urban-capital-pwa/

├── manifest.json   ← Configuração PWA
```
